# Security Audit Evidence Reports

Automates generation of Oracle security audit evidence reports for bank IT
auditors — converts SQL*Plus spool output into formatted Word documents.

> **Status:** Structure created, scripts not yet uploaded to this repo.

## Design goals

- Zero-dependency Python approach, required because the audit-report servers
  are air-gapped (no internet/repo access, so no `pip install`).
